# BCPアラート 分離版

テン・メモ本体からBCP機能だけを分離した、Edgeサイドパネル用の独立拡張です。

## 主な機能

- 気象庁の地震情報（直近24時間）
- 全国の気象警報・注意報
- 気象庁の台風情報
- 地震・気象警報・台風それぞれの通知ON/OFF
- 地震・気象警報・台風それぞれの巡回間隔設定
- BCP全体の自動更新ON/OFF
- 自動更新OFF中も「今すぐ更新」は利用可能
- 気象警報の「レベル順 / 新着順」切替（デフォルトはレベル順）
- 気象警報は最高警戒レベルに応じてカードを強調表示
- 震度3以上の地震を強調表示
- 台風の発生・勢力上昇通知、予報表示、終了後のグレー表示

## インストール

1. `standalone-bcp` フォルダをPCへ用意します。
2. Edgeで `edge://extensions/` を開きます。
3. 「開発者モード」をONにします。
4. 「展開して読み込み」を押します。
5. `standalone-bcp` フォルダを選択します。

テン・メモ本体とは別の拡張機能として動作します。そのため、設定や取得履歴などのChrome/Edge拡張ストレージは本体とは独立します。
